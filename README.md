# Frontend Design Sandbox

A collection of lightweight frontend UI components, responsive layout exercises, and vanilla JavaScript interactions.

## 🚀 Features
- Clean modern dark-theme styling inspired by developer tooling interfaces.
- Responsive multi-column layout using modern CSS Grid and Flexbox.
- Zero external build dependencies — pure HTML5, CSS3, and modern ECMAScript.

## 📦 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/zahramaulana600/sandbox-project-09162025.git
   ```
2. Open `index.html` in any modern web browser.
